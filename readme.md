# Отладка NASM-программ в GDB с TUI

## 1. Сборка с отладочной информацией

Чтобы видеть исходные строки и метки в GDB, ассемблируйте с флагом `-g`:

```bash
nasm -f elf64 -g program.asm -o program.o
```

Линковка в исполняемый файл:

```bash
ld program.o -o pro
```

## 2. Запуск GDB в многооконном режиме (TUI)

Для разделения экрана на окна исходного кода и ассемблера:

```
layout split
```

Для отображения регистров в отдельном окне:

```
layout regs
```

Переключение между окнами: **`Ctrl-x` затем `o`**.  
Прокрутка активного окна: стрелки.

## 3. Автоматический показ ассемблерной строки при шагах

### Способ 1: включить отображение следующей инструкции

```
set disassemble-next-line on
```

Теперь после каждого `ni`/`si` будет выводиться строка дизассемблера, например:

```
=> 0x401027 <_start.first_symbol+3>: cmp    dl,0x9
```

### Способ 2: показывать текущую инструкцию всегда

```
display/i $pc
```

Эта команда заставляет GDB выводить инструкцию по адресу `$pc` после каждой остановки.

### Способ 3: ручной вывод при необходимости

```
x/i $pc
```

## 4. Полезные TUI-раскладки

| Команда          | Что отображает                            |
|------------------|-------------------------------------------|
| `layout src`     | Только исходный код (требуется `-g`)      |
| `layout asm`     | Только дизассемблированный код            |
| `layout split`   | Исходный код + дизассемблер               |
| `layout regs`    | Регистры + командная строка               |
| `layout src`     | Исходный код + командная строка           |

## 5. Пример сеанса отладки

```bash
gdb ./pro
```

```
(gdb) set disassemble-next-line on
(gdb) display/i $pc
(gdb) break _start
(gdb) run
(gdb) ni
```

При каждом нажатии `ni` вы будете видеть выполняемую инструкцию и текущее состояние программы.

> **Совет:** чтобы настройки сохранялись, добавьте `set disassemble-next-line on` и `display/i $pc` в файл `~/.gdbinit`.

## 6. Примечание о символах табуляции, пробела и перевода строки

При сравнении байтов в NASM используйте числа или обратные кавычки для управляющих символов:

```nasm
cmp al, 9      ; табуляция
cmp al, 32     ; пробел
cmp al, 10     ; перевод строки (LF)
```

или

```nasm
cmp al, `\t`
cmp al, `\n`
```
